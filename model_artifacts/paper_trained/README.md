# Paper-Trained Model Artifacts

This directory contains the trained fold-wise artifacts of the AER-GT full model reported in the manuscript. For each of the five subject-level folds it holds the pretrained checkpoint (after self-supervised pretraining on the normative-baseline cohort), the final checkpoint (after supervised fine-tuning), and the feature scaler fitted on the pretraining cohort.

Contents:

- `checkpoints/fold_<k>_pretrained.pth`: model parameters after pretraining.
- `checkpoints/fold_<k>_final_model.pth`: model parameters after fine-tuning (the model evaluated in the manuscript).
- `scalers/fold_<k>_scaler.pkl`: feature standardization fitted on the pretraining cohort.
- `artifact_manifest.json`: architecture and training settings, and the file list with sizes and SHA-256 hashes.

Each checkpoint stores the model parameters only; no training configuration, sample identifiers, or data are embedded. Result tables, figures, out-of-fold prediction tables, and interpretability arrays are not included and are regenerated by running the pipeline.

To run inference with these artifacts, place the private labeled dataset under `data/private/labeled_epilepsy/` and run:

```bash
python scripts/run_inference.py --config configs/paper_trained_inference.yaml
```

The scaler files were written with NumPy 2 and load only in the environment defined by `environment.yml`.
