# Paper-Trained Model Artifacts

This directory is reserved for the trained fold artifacts corresponding to the manuscript results.

Included artifact types:

- `checkpoints/fold_*_final_model.pth`
- `checkpoints/fold_*_pretrained.pth`
- `scalers/fold_*_scaler.pkl`
- `artifact_manifest.json`

Excluded generated outputs:

- Precomputed reference metric tables (regenerated by running the pipeline).
- Figure images and vector files.
- Out-of-fold prediction tables with per-window source paths.
- Raw interpretability `.npz` files.
- Legacy summaries containing local absolute paths.

Run inference with these artifacts after placing the private labeled dataset under `data/private/labeled_epilepsy/`:

```bash
python scripts/run_inference.py --config configs/paper_trained_inference.yaml
```

Use the repository environment (`joblib>=1.4`, `scikit-learn>=1.3`) when loading the bundled scaler files. Older local environments may fail to deserialize these artifacts.
