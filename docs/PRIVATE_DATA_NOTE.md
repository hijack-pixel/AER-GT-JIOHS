# Private Data Note

The complete widefield IOS recordings and the full processed graph-sample dataset are not included in this repository.

Reason:

- The data are derived from animal experimental recordings held by the research group and institution.
- Public redistribution requires institutional and author approval.

The data and code availability statement of the manuscript applies to this repository:

```text
The code, preprocessing scripts, and trained model artifacts are available at https://github.com/hijack-pixel/AER-GT-JIOHS. The original IOS recordings and the full processed dataset are available from the corresponding author upon reasonable request (expected response time: within 30 days; a data-use agreement may be required).
```

Requests are directed to the corresponding author. Authorized users who hold the processed `.mat` graph samples can place them under `data/private/` (ignored by git) and run the full pipeline; the expected layout is described in `docs/DATA_FORMAT.md`.
