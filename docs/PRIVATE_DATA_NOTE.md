# Private Data Note

The complete widefield IOS recordings and the full processed graph-sample dataset are not included in this repository.

Reason:

- The data are derived from animal experimental recordings held by the research group and institution.
- Public redistribution requires institutional and author approval.

Recommended manuscript wording:

```text
The code used for model training, evaluation, and ablation analysis is available at [repository link]. The raw and full processed IOS datasets are not publicly distributed because they contain private animal experimental data managed by the authors' institution. Data supporting the findings may be requested from the corresponding authors, subject to institutional approval and reasonable data-use conditions. A synthetic demo dataset is provided with the code to verify the software workflow but is not intended to reproduce the manuscript's quantitative results.
```
