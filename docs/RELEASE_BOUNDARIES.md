# Release Boundaries

This repository separates source code, reusable trained artifacts, private-data placeholders, demo data generation, and generated outputs.

## Versioned

- Source code under `src/` and `scripts/`.
- YAML configs under `configs/`.
- Parameterized MATLAB raw TIFF-to-graph preprocessing under `preprocess/matlab/`, with placeholder specification tables under `preprocess/spec/`.
- MATLAB Fig. 4 IOS state-analysis code under `preprocess/fig4/`.
- Documentation under `docs/`.
- Lightweight smoke tests under `tests/`.
- Paper-trained model artifacts under `model_artifacts/paper_trained/` (checkpoints, scalers, README, and manifest).

## Not Versioned

- Raw IOS recordings.
- Full processed private `.mat` datasets.
- Filled-in specification tables (animal identifiers, file names, registration landmarks).
- Synthetic demo `.mat` files generated by `scripts/create_synthetic_demo_data.py`.
- Precomputed result tables (confusion matrices, fold/summary metric tables, training histories); these are written to the ignored `outputs/` directory when the pipeline is run.
- Everything under `outputs/` except `outputs/.gitkeep`, including MATLAB preprocessing quality reports and figures.
- Figure outputs and intermediate arrays such as the interpretability `.npz` files.
- Out-of-fold prediction tables, which carry recording identifiers and local paths.

## Rationale

The repository lets readers inspect the complete code path and run a minimal demo, while private animal data stay with their holders.
