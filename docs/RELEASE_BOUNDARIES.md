# Release Boundaries

This repository separates source code, reusable trained artifacts, private data placeholders, demo data generation, and generated outputs.

## Versioned

- Source code under `src/` and `scripts/`.
- YAML configs under `configs/`.
- Parameterized MATLAB raw TIFF-to-graph preprocessing under `preprocess/matlab/`.
- MATLAB Fig.4 IOS state-analysis metric code under `preprocess/fig4/`.
- Documentation under `docs/`.
- Lightweight smoke tests under `tests/`.
- Paper-trained model artifacts under `model_artifacts/paper_trained/` (checkpoints and scalers only).

## Not Versioned

- Raw IOS recordings.
- Full processed private `.mat` datasets.
- Synthetic demo `.mat` files generated by `scripts/create_synthetic_demo_data.py`.
- Precomputed result tables (confusion matrices, fold/summary metric tables, training histories); these are written to the ignored `outputs/` directory when the pipeline is run, and are not bundled with the repository.
- Any content under `outputs/` except `outputs/.gitkeep`.
- MATLAB preprocessing quality reports generated under `outputs/preprocess_quality/`.
- Figure outputs such as `.png`, `.pdf`, and generated `.svg` files.
- Large intermediate arrays such as interpretability `.npz` outputs.
- Full out-of-fold prediction tables if they contain private source-file paths.

## Rationale

The repository should let reviewers inspect the full code path and run a minimal demo, while avoiding accidental release of private animal data or transient figure outputs.
