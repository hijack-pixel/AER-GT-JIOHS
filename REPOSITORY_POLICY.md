# Repository Policy

This repository is the code and model-artifact companion of the manuscript. It is organized so that the complete computational path can be inspected and run without the private animal data.

## Included

- Source code for preprocessing, training, subject-level evaluation, baselines, ablations, interpretability, and the supplementary analyses.
- Configuration-driven training and evaluation (`configs/`); the Python pipeline contains no local paths.
- Fold-wise paper-trained checkpoints and scalers (`model_artifacts/paper_trained/`).
- A synthetic demo data generator and smoke tests that validate the software workflow.
- Documentation of the processed `.mat` sample format, the reproduction steps, and the release boundaries.

## Not Included

- Raw IOS recordings and the full processed graph-sample dataset (private animal experimental data); see `CODE_AND_DATA_AVAILABILITY.md`.
- Generated outputs: result tables, figures, out-of-fold prediction tables, and intermediate interpretability arrays. They are regenerated by the scripts.

The synthetic demo data are non-biological and serve only to validate the software workflow; they cannot reproduce the quantitative results of the manuscript.

Animal identifiers of the private dataset are not part of the repository. Tables in the manuscript number the five ictal-transition animals Mouse 1-5 in ascending order of their dataset identifiers; the analysis scripts apply the same rule to their outputs.
