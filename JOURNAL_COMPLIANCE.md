# Submission-Oriented Checklist

This repository is organized as a journal submission package.

## Included

- Code and data availability statement draft.
- Clear separation between source code, demo data, private data placeholders, and generated outputs.
- Configuration-driven training and evaluation.
- No hard-coded local Windows drive paths in the Python model pipeline.
- Synthetic demo data generator for workflow verification.
- Data format documentation for processed MATLAB `.mat` graph samples.
- Release boundary documentation distinguishing versioned model artifacts from generated outputs.

## To Complete Before Public Release

- Add the final DOI or persistent archive link if the GitHub repository is archived through Zenodo/Figshare.
- Choose and confirm a code license with all authors.
- Replace placeholder contact language in `docs/PRIVATE_DATA_NOTE.md` if the institution requires a specific access process.
- Add a small real de-identified sample only if all authors and the institution approve it.
